# LP Rebalancer — v0.2

**Назначение:** мониторинг позиции ликвидности PancakeSwap V3 с подготовкой к автоматическому ребалансированию.

## Реализованный функционал

- **Подключение к блокчейну:** работа с Base Sepolia через RPC.
- **Получение данных пула:** текущая цена, tick, комиссия и tick spacing.
- **Мониторинг LP-позиции:** чтение NFT-позиции, ликвидности и границ диапазона.
- **Контроль диапазона:** определение, находится ли текущая цена внутри диапазона позиции.
- **Оценка активов:** расчёт количества токенов и учёт начисленных комиссий.
- **Оценка стоимости:** получение USD-цен через оракул с проверкой актуальности данных.
- **Конфигурация:** параметры сети, пула и ценового оракула задаются через конфигурационный файл.
- **Тестирование:** 16 автоматических тестов пройдено в последнем известном состоянии.

## Текущие ограничения

Полный автоматический ребалансер пока не реализован. Сбор комиссий, закрытие старой позиции и открытие новой ещё не объединены в полный рабочий цикл.
